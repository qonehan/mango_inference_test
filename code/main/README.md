# 본 실험 코드

설계는 [docs/13](../../docs/13_본실험_설계.md), 결과는 [docs/14](../../docs/14_본실험_결과.md)를 봅니다.

- [exp1/](exp1/README.md): 본 실험 1(OR 기본 라우팅 관측) 호출 · 수집 · 선택 모형 · 고정 경로 선정
- [exp2/](exp2/README.md): 본 실험 2(Mango vs OR 엔드포인트) 측정기 · 공개 지표 수집 · 집계 · 환산 · 예상 점유율

작업 당시 비공개 작업 폴더에서 실행한 코드를 그대로 옮겼습니다. 그래서 일부 스크립트의 입출력 경로(`90_작업자료/...`, `08_도구/...`)는 이 저장소 구조와 다릅니다. 공개본에서 바꾼 것은 HTTP User-Agent 문자열(`mango-bench/1.0`)뿐입니다. API 키는 환경변수(`OPENROUTER_API_KEY`, `MANGO_API_KEY`)로 읽고, 실제 호출은 과금됩니다.
