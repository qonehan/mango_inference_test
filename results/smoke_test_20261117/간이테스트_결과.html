정렬과 접미사

  • sort: "price": 기본 배분을 건너뛰고 가격이 낮은 엔드포인트부터 시도
  • :floor: 가격순 정렬 + 할인된 flex 등급 엔드포인트도 후보에 넣음
  • sort: "throughput": 처리량이 높은 엔드포인트부터 시도
  • :nitro: 처리량순 정렬 + 빠른 priority 등급 엔드포인트도 후보에 넣음

이번 1회 호출에서는 4개 모델 모두 :floor가 가격순과, :nitro가 처리량순과 같은 엔드포인트로 갔습니다.

경로별로 달라지는 부분

  • Mango 직접: api.mangoboost.io/v1, model = Mango 모델 ID
  • OpenRouter 기본: provider 설정 없음
  • 고정: "provider": {"order": ["제공사"], "allow_fallbacks": false}
  • 정렬: "provider": {"sort": "price" | "throughput" | "latency"}
  • :floor, :nitro: 모델 이름 뒤에 접미사
