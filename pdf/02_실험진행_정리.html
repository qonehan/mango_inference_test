## 2026-11-17 재검토 반영: 확정 분석 규칙 (v0.9.1)

이 절은 앞 절의 충돌하는 정의보다 우선합니다. v1.0 동결 전 초안이며 본 측정은 실행하지 않았습니다. 구현 기준은 `code/analysis_metrics.py`, 검증은 `code/test_analysis_metrics.py`입니다.

1. **P3 성공률:** W1·W3·W2 각각의 성공률 차이를 1/3씩 가중합니다. W2는 세션을 하나의 이항 관측으로 봅니다. 무실패에서도 0폭 구간이 되는 백분위 부트스트랩을 사용하지 않습니다. 모델별 오류 확률 alpha=0.05/16을 6개 주변 성공률(M·OR × 3작업)에 alpha/6씩 배분하고 각각 양측 Clopper–Pearson 구간을 구합니다. 차이 구간은 [sum(w*(L_M-U_OR)), sum(w*(U_M-L_OR))]입니다. 짝의 의존성과 무관하게 합집합 상계로 보수적으로 보장하며 짝지음의 효율은 포기합니다. 요청·세션 간 독립을 가정하므로 시간 상관은 한계로 보고합니다. 미측정 작업이나 독립 표본이 없는 작업이 있으면 판정 불가입니다. ±2%p 동등 기준은 유지하되 이 예산으로 판정 불가가 나올 수 있음을 명시합니다.

2. **P4 성공 세션당 비용:** 경로별 C=sum(계획된 공통 W2 세션에서 발생한 모든 청구액)/성공 세션 수, 통계량 C_M/C_OR입니다. 실패 세션의 청구액과 중단 전 완료 턴도 포함합니다. 세션 한 턴이 실패하면 그 세션의 나머지 턴은 보내지 않습니다. 비용 미확인은 0으로 채우지 않으며 주 비용 판정은 보류합니다. 성공 0건 또는 OR 비용 0이면 비율 판정 불가입니다. 회차별로 전체 세션 쌍을 재표본하고 매번 비용 합·성공 수를 다시 계산합니다. 분모가 0인 재표본은 삭제하지 않고 전체 비용 구간 판정을 보류합니다. 99.6875% 백분위 구간, 10,000회, 시드 20261116. 양쪽 성공 세션만의 비용 기하평균은 보조 지표로만 보고합니다.

3. **P2 스트림 처리량:** usage 전용·역할·빈 조각을 제외한 첫·마지막 생성 내용(reasoning/content/tool) 조각 시각을 사용합니다. completion이 reasoning을 포함함을 확인하고, reasoning 토큰이 양수인데 reasoning 스트림이 전혀 없거나 보고값이 결측이면 decode는 산출 불가입니다. 생성 내용 조각이 2개 미만, completion<=1, 시간차<=0도 산출 불가입니다. 관측 가능한 경우 (completion-1)/(마지막 생성 내용-첫 생성 내용)로 계산하되 첫 조각에 여러 토큰이 포함되는 근사임을 표시합니다. E2E는 정상 스트림 종료까지의 시간이며 completion/E2E를 모든 경로의 보조 지표로 보고합니다. decode 결측은 0이나 E2E 처리량으로 대체하지 않습니다. 공통 W1 쌍의 어느 쪽이든 구조적으로 decode를 관측할 수 없으면 해당 모델 P2 전체 판정은 보류하고 관측 가능 부분집합 결과만 탐색적으로 보고합니다.

4. **라우팅 구간:** 요청 건수 비중만 Wilson 구간을 사용합니다(독립 요청 가정의 한계 명시). 최종 응답 제공사의 토큰 비중은 회차 × 작업을 층으로 요청 전체를 재표본하며, 매번 제공사별 입력+출력 토큰 합/전체 토큰 합을 재계산합니다(10,000회, 시드 20261116, 95% 구간). 토큰을 독립 시행으로 세지 않습니다. 첫 시도 분포는 요청 건수로만 보고하며 최종 응답 토큰을 첫 시도에 귀속하지 않습니다. 실패·토큰 결측 건수와 미귀속 토큰을 별도 보고하고, 응답·토큰이 확인된 요청에 조건부인 비중임을 명시합니다. 공개 30일 점유율과의 차이는 탐색적 구성 차이일 뿐입니다.

5. **시간 블록:** M·OR 주 비교 W1/W3 질문 쌍 또는 W2 세션 쌍을 하나의 블록으로 배치합니다. 블록마다 두 경로 순서를 시드로 무작위화하고, 모델별 두 요청을 연속 배치합니다. 계정 속도 제한은 준수하며 다른 탐색 요청은 쌍 사이가 아닌 블록 사이에 균등 배치합니다. W2는 세션 쌍 내부에서 각 경로 10턴을 순차 실행합니다. 블록 ID·양쪽 시작 시각·짝 간 시차를 보존하고 시차 분포와 회차별 민감도 분석을 보고합니다. 6시간 회차 안에 있다는 이유만으로 동시 조건으로 취급하지 않습니다.

6. **실패 후 축소:** 실패율 50% 초과여도 M·OR-기본의 공통 W1/W3/W2 주 비교는 예정 수량을 유지합니다. 축소는 탐색용 경로·추가 라우팅 요청에만 적용합니다. 예산·장애로 주 비교 수량을 채우지 못하면 미실행을 서비스 실패로 대입하지 않고 미측정으로 기록하며 해당 모델 전체 기간의 주 판정을 보류합니다. 실행 후 실패와 실행 전 미측정을 구분합니다.

7. **정의 정합성:** W2 주 P1 세션값은 2~10턴 TTFT(content)의 기하평균입니다. 산술평균은 보조 통계입니다. 본 측정용 세션 풀 48개와 파일럿용 별도 6개를 만들고 재사용하지 않습니다. 파일럿 분산 산정은 정밀도 계획용 근사이며 32~48 상한은 검정력 보장이 아닙니다. 일반 JSON 직렬화 전체의 접두부가 아닌 정규화한 메시지 목록의 기존 메시지 불변성과 텍스트 바이트를 검사합니다. 서버 템플릿 이후 토큰 접두부는 직접 확인할 수 없으므로 실제 캐시 적중은 usage로 검증합니다.
