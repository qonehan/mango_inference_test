## 2026-11-17 v0.9.2 반영

- P3는 성공률 차이 구간 추정용으로 전환. 현 표본에서 ±2%p 동등 판정을 하지 않음.
- Q에 OR-기본 추가: 400문항 × 7경로 × 4모델 = 11,200건. 품질 허용 범위와 미확인 표시 규칙은 프로토콜 2-2절 적용.
- Mango 비용은 단가 추정과 실제 정산을 분리. 차액 일괄 비례 배분 금지, W2 귀속 불명 시 P4 판정 보류.
- W2는 고정 대화 재생 성능·프로토콜 성공률로 제한. 실제 과제 달성률은 측정하지 않음.
- 현재 규칙은 [프로토콜 v0.9.2](02_실험_프로토콜.md)에 통합. 기존 정정 절 링크·PDF는 과거 이력이며 현재 기준이 아님.
- 다음 순서: 본 runner·Q 채점기 구현 → 모의 서버 검증 → 파일럿(비용·품질 구간 정밀도 포함) → v1.0 동결 → 본 측정. 실행 날짜는 미확정.
