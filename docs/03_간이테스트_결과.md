## Mango 응답 형식 확인

- 스트리밍 usage가 마지막 조각에 옴(`stream_options.include_usage`). reasoning 토큰도 대부분 보고됨.
- **GLM-5.3은 usage 형식이 다름.** reasoning 토큰은 OpenAI 표준 위치(`completion_tokens_details.reasoning_tokens`)가 아니라 `usage.reasoning_tokens`에 있음(텍스트 102, 도구 25). Mango 문서도 모델에 따라 두 위치 중 하나를 쓴다고 안내함. 캐시 토큰 세부(`prompt_tokens_details`)는 없음 → GLM-5.3의 캐시 효과는 W2 1턴과 2~10턴의 응답 시간 차이로 간접 측정. (처음에 reasoning도 보고하지 않는다고 적었던 것은 오류였고 2026-11-17 정정)

결론: **현재 실제 청구는 API 단가(할인 전 가격) 그대로입니다.** 공식 페이지의 30% 할인은 이 계정에 적용되지 않았거나 다른 조건의 가격으로 보입니다. 센트 단위 반올림 때문에 정밀도는 낮으므로, 본 실험에서 회차별 잔액 차이로 다시 확인합니다.

## 관찰 (1회 호출이라 참고만)

- 정렬 경로는 예상대로 움직였습니다. 가격순·`:floor`는 주로 Wafer·Relace, 처리량순·`:nitro`는 CoreWeave·Alibaba·Particle AI·InferenceNet.
- GLM-5.3-Flash와 Kimi는 일부 호출에서 reasoning이 길어 첫 답변까지 15초 이상 걸렸습니다. 본 실행의 출력 상한을 크게 둔 이유와 맞습니다.
